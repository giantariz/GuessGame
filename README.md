# GuessGame — Closest Quiz Game Pro

Ένα διαδραστικό παιχνίδι εκτίμησης αριθμών για παρέες και τάξεις, που τρέχει εξ ολοκλήρου στον browser **χωρίς εγκατάσταση, χωρίς server και χωρίς εξαρτήσεις**.

> Σλόγκαν: *«Κερδίζει ο λιγότερο λάθος.»*

## Τι είναι

Οι παίκτες καλούνται να μαντέψουν αριθμητικές απαντήσεις (π.χ. πληθυσμός χώρας, χρονολογία γεγονότος, θερμοκρασία, απόσταση). Δεν χρειάζεται να βρουν την ακριβή τιμή — **κερδίζει όποιος πλησιάσει περισσότερο** στη σωστή απάντηση. Το παιχνίδι λειτουργεί ως «host mode»: ένας συντονιστής διαβάζει την ερώτηση, οι παίκτες γράφουν την εκτίμησή τους, και ο host αποκαλύπτει την απάντηση και απονέμει τους πόντους.

Υποστηρίζει πολλαπλούς παίκτες, 12 κατηγορίες ερωτήσεων, ρυθμιζόμενο χρονόμετρο, αυτόματη αποθήκευση κατάστασης, καθώς και δημιουργία custom ερωτήσεων μέσω AI.

## Χαρακτηριστικά

- **Βάση ερωτήσεων** — 100 έτοιμες ερωτήσεις σε 12 κατηγορίες (Γεωγραφία, Ιστορία, Επιστήμη, Αθλητισμός, Pop Culture, Μουσική, Τεχνολογία, Ελλάδα, Φύση & Ζώα, Φαγητό & Ποτό, Καθημερινά, Αστεία).
- **Διαχείριση παικτών** — Προσθήκη/αφαίρεση παικτών, χειροκίνητη ρύθμιση σκορ (+1/−1), μηδενισμός σκορ, μετρητής παικτών (badge) στην καρτέλα.
- **Live scoreboard** — Πίνακας βαθμολογίας τόσο μέσα στο παιχνίδι όσο και στην καρτέλα Παίκτες, ταξινομημένος αυτόματα κατά σκορ.
- **Χρονόμετρο** — Ρυθμιζόμενο από 5 έως 300 δευτερόλεπτα ανά ερώτηση, με οπτική μπάρα προόδου.
- **Δύο λειτουργίες παιχνιδιού** — **Τυχαία** (χωρίς επανάληψη μέχρι να εξαντληθεί η δεξαμενή) ή **Σειριακή** (με τη σειρά).
- **Φιλτράρισμα ανά κατηγορία** — Παίξε μόνο με τις κατηγορίες που σε ενδιαφέρουν, ή με όλες.
- **Αναζήτηση στη βάση** — Καρτέλα Ερωτήσεις με αναζήτηση σε κατηγορία, ερώτηση και απάντηση.
- **Αποκάλυψη απάντησης με blur** — Η σωστή απάντηση εμφανίζεται θολή και αποκαλύπτεται με κουμπί.
- **AI Prompt Generator** — Φτιάχνει έτοιμο prompt (με βάση τις επιλεγμένες κατηγορίες & αριθμό ερωτήσεων) για αντιγραφή σε AI tool, και φορτώνει το JSON αποτέλεσμα.
- **Επαναφορά default** — Επιστροφή στο αρχικό σετ των 100 ερωτήσεων με ένα κλικ.
- **Αυτόματη αποθήκευση** — Παίκτες, σκορ, πρόοδος και custom ερωτήσεις αποθηκεύονται στο `sessionStorage`· με banner επιβεβαίωσης όταν αποκαθίσταται η συνεδρία.
- **Θέματα** — Light / Dark mode με ένα κουμπί.
- **Responsive & accessible** — Fluid typography, ARIA tabs/labels, mobile-first σχεδιασμός.
- **Μηδενικές εξαρτήσεις** — Καθαρή HTML/CSS/JS, κανένα build step, κανένα `npm install`.

## Εκκίνηση

Δεν απαιτείται εγκατάσταση ή server. Απλά ανοίξτε το `index.html` στον browser:

```bash
# Κλωνοποιήστε το repository
git clone https://github.com/giantariz/guessgame.git
cd guessgame

# Ανοίξτε στον browser
open index.html       # macOS
xdg-open index.html   # Linux
start index.html      # Windows
```

Ή απλά κάντε διπλό κλικ στο `index.html`.

> **Σημείωση:** Οι γραμματοσειρές (Google Fonts) και το script στατιστικών (GoatCounter) φορτώνονται από το διαδίκτυο. Χωρίς σύνδεση, το παιχνίδι παίζει κανονικά με fallback γραμματοσειρές.

## Πώς παίζεται

1. Μεταβείτε στην καρτέλα **👥 Παίκτες** και προσθέστε τα ονόματα όλων των παικτών (τουλάχιστον δύο).
2. Στην καρτέλα **⚡ Παιχνίδι** ρυθμίστε το χρονόμετρο, την κατηγορία και τη λειτουργία στις **Ρυθμίσεις**.
3. Πατήστε **«🎲 Ας παίξουμε!»** — διαβάστε την ερώτηση δυνατά. Κάθε παίκτης γράφει την εκτίμησή του κρυφά.
4. Όλοι αποκαλύπτουν τις απαντήσεις τους ταυτόχρονα.
5. Πατήστε **«👁 Δείξε την απάντηση»** για να εμφανιστεί η σωστή τιμή.
6. Δώστε **+1 πόντο** στον παίκτη που πλησίασε περισσότερο, μέσα από το scoreboard κάτω από την ερώτηση.
7. Πατήστε **«⏭ Επόμενη ερώτηση»** και συνεχίστε. Στο τέλος κερδίζει ο παίκτης με τους περισσότερους πόντους.

## Δημιουργία ερωτήσεων με AI

Στην καρτέλα **✨ Δημιουργία** μπορείτε να φτιάξετε το δικό σας σετ ερωτήσεων:

1. Επιλέξτε τις **κατηγορίες** που θέλετε (checkboxes) και τον **αριθμό ερωτήσεων** (1–200).
2. Πατήστε **«✨ Δημιουργία Prompt»** — παράγεται έτοιμο κείμενο prompt στα Ελληνικά.
3. Πατήστε **«📋 Αντιγραφή prompt»** και επικολλήστε το σε ένα AI tool (συνιστάται το **Perplexity** για πιο ακριβή αποτελέσματα).
4. Αντιγράψτε το **JSON** που θα σας δώσει το AI και επικολλήστε το στο πεδίο **«JSON από AI»**.
5. Πατήστε **«⬆ Φόρτωσε ερωτήσεις»** — το παιχνίδι θα χρησιμοποιεί πλέον **μόνο** αυτές τις ερωτήσεις.
6. Με **«↺ Επαναφορά default»** επιστρέφετε στις αρχικές 100 ερωτήσεις.

### Μορφή JSON

Οι ερωτήσεις είναι ένα **μη κενό array** αντικειμένων με τρία υποχρεωτικά πεδία τύπου string:

```json
[
  {
    "category": "Γεωγραφία",
    "question": "Πόσα χιλιόμετρα είναι η ακτογραμμή της Ελλάδας;",
    "answer": "≈ 13.676 km"
  }
]
```

Το JSON επικυρώνεται κατά τη φόρτωση (`validateImportedQuestions`): αν λείπει πεδίο, είναι κενό, ή το array είναι άδειο, εμφανίζεται σαφές μήνυμα σφάλματος και δεν φορτώνεται τίποτα.

## Τεχνική τεκμηρίωση

### Μοντέλο δεδομένων

**Ερώτηση** (στοιχείο του `defaultQuestions` / custom array):

```js
{ category: string, question: string, answer: string }
```

**Παίκτης**:

```js
{ id: string /* crypto.randomUUID() */, name: string, score: number /* ≥ 0 */ }
```

Το σκορ δεν πέφτει ποτέ κάτω από το 0 (`adjustPlayerScore` εφαρμόζει `Math.max(0, …)`).

### Κατάσταση παιχνιδιού (state)

Όλη η κατάσταση ζει σε module-level μεταβλητές στο `game.js`:

| Μεταβλητή | Ρόλος |
|---|---|
| `questions` | Το ενεργό σετ ερωτήσεων (default ή custom). |
| `players` | Λίστα παικτών. |
| `round` | Τρέχων αριθμός γύρου. |
| `usedQuestionIndexes` | Δείκτες ερωτήσεων που έχουν παιχτεί (για τυχαία λειτουργία χωρίς επανάληψη). |
| `currentQuestionIndex` | Δείκτης τρέχουσας ερώτησης (ή `null`). |
| `sequencePointer` | Θέση για τη σειριακή λειτουργία. |
| `timerInterval`, `timeLeft`, `currentDuration` | Κατάσταση χρονομέτρου. |
| `answerRevealed` | Αν έχει αποκαλυφθεί η απάντηση. |
| `theme` | `'light'` ή `'dark'`. |

### Αποθήκευση συνεδρίας (sessionStorage)

Κλειδί: `quizGameSession`. Αποθηκεύεται μετά από κάθε σημαντική ενέργεια (`saveSession`).

```js
{
  players,                 // λίστα παικτών
  round,                   // αριθμός γύρου
  usedQuestionIndexes,     // δείκτες που έχουν παιχτεί
  sequencePointer,         // θέση σειριακής λειτουργίας
  isCustomQuestions,       // boolean: αν χρησιμοποιούνται custom ερωτήσεις
  customQuestions          // το custom array, ή null
}
```

Σημεία προσοχής:

- **Scope:** `sessionStorage` → η κατάσταση κρατά **όσο μένει ανοιχτή η καρτέλα του browser**· κλείνοντάς την, καθαρίζει. (Το **θέμα** δεν αποθηκεύεται.)
- **Επαναφορά:** στο load, η `loadSession` επικυρώνει αυστηρά τα δεδομένα (τύποι, μη αρνητικά σκορ, έγκυρα custom questions). Αν κάτι δεν στέκει, η συνεδρία απορρίπτεται καθαρά. Σε επιτυχία εμφανίζεται προσωρινό **banner** («Η συνεδρία αποκαταστάθηκε…»).
- **Ανθεκτικότητα:** το `saveSession` τυλίγεται σε `try/catch` ώστε quota ή security errors να μην κρασάρουν το παιχνίδι.

### Επιλογή ερωτήσεων

`getFilteredIndexes` επιστρέφει τους δείκτες που ταιριάζουν στην επιλεγμένη κατηγορία (ή όλους). `pickNextQuestionIndex`:

- **Σειριακή:** βρίσκει την επόμενη επιλέξιμη ερώτηση από τον `sequencePointer` και τυλίγεται στην αρχή όταν τελειώσει.
- **Τυχαία:** διαλέγει τυχαία από όσες **δεν** έχουν παιχτεί· όταν εξαντληθούν, μηδενίζει το `usedQuestionIndexes` και ξαναρχίζει.

### Χρονόμετρο

`startTimer(duration)` ξεκινά `setInterval` ανά δευτερόλεπτο, ενημερώνει το πλάτος της μπάρας (`updateTimerUI`) και σταματά στο 0. `stopTimer` καθαρίζει το interval (καλείται και στην αποκάλυψη απάντησης και στο νέο παιχνίδι).

### Σύστημα θεμάτων

Τα χρώματα ορίζονται ως CSS variables κάτω από `[data-theme="light"]` και `[data-theme="dark"]` στο `style.css`. Το `applyTheme()` αλλάζει το `data-theme` attribute στο `<html>` και το εικονίδιο/aria-label του toggle. Όλα τα μεγέθη γραμματοσειράς χρησιμοποιούν `clamp()` για fluid typography.

### Προσβασιμότητα

- Πλήρης ARIA σήμανση στα tabs (`role="tablist"`, `role="tab"`, `aria-selected`, `aria-controls`) και στα panels (`role="tabpanel"`).
- Περιγραφικά `aria-label` σε κουμπιά (theme toggle, κλείσιμο banner).
- Στόχοι αφής ≥ 44px, σημασιολογικά headings, υποστήριξη πληκτρολογίου (Enter για προσθήκη παίκτη).

### Στατιστικά / Analytics

Φορτώνεται το **GoatCounter** (`gc.zgo.at/count.js`) για ανώνυμα στατιστικά επισκεψιμότητας, χωρίς cookies. Δεν επηρεάζει το gameplay και μπορεί να αφαιρεθεί διαγράφοντας το αντίστοιχο `<script>` στο τέλος του `index.html`.

### Αναφορά συναρτήσεων

| Συνάρτηση | Περιγραφή |
|---|---|
| `applyTheme()` | Εφαρμόζει το ενεργό θέμα στο DOM. |

## Ανάπτυξη & συνεισφορά

- **Προσθήκη μόνιμων ερωτήσεων:** επεξεργαστείτε το array `defaultQuestions` στο `questions.js` (τρία πεδία: `category`, `question`, `answer`).
- **Προσωρινές ερωτήσεις:** χρησιμοποιήστε την καρτέλα Δημιουργία (δεν αλλάζει αρχεία — ζει στη συνεδρία).
- **Στυλ/θέματα:** όλα τα χρώματα & μεγέθη είναι CSS variables στην αρχή του `style.css`.
- **Δοκιμή:** ανοίξτε το `index.html` σε browser· δεν χρειάζεται build ή server.
