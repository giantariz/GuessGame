# GuessGame — Closest Quiz Game Pro

Ένα διαδραστικό παιχνίδι εκτίμησης αριθμών για ομάδες, που τρέχει εξ ολοκλήρου στον browser χωρίς εξαρτήσεις.

## Τι είναι

Οι παίκτες καλούνται να μαντέψουν αριθμητικές απαντήσεις (π.χ. πληθυσμός χώρας, χρονολογία γεγονότος, θερμοκρασία). Κερδίζει όποιος απαντήσει πιο κοντά στη σωστή τιμή. Το παιχνίδι υποστηρίζει πολλαπλούς παίκτες, κατηγορίες ερωτήσεων και προσαρμόσιμες ρυθμίσεις.

## Χαρακτηριστικά

- **Ερωτήσεις** — 100+ ερωτήσεις σε 12 κατηγορίες (Γεωγραφία, Ιστορία, Επιστήμη, Αθλητισμός, Pop Culture, Μουσική, Τεχνολογία κ.ά.)
- **Διαχείριση παικτών** — Προσθήκη/αφαίρεση παικτών, χειροκίνητη ρύθμιση σκορ (+1/−1), live leaderboard
- **Χρονόμετρο** — Ρυθμιζόμενο από 5 έως 300 δευτερόλεπτα ανά ερώτηση
- **Λειτουργίες παιχνιδιού** — Τυχαία ή σειριακή επιλογή ερωτήσεων, φιλτράρισμα ανά κατηγορία
- **Εισαγωγή ερωτήσεων** — Προσθήκη custom ερωτήσεων μέσω JSON
- **AI Prompt Generator** — Δημιουργία νέων ερωτήσεων με AI
- **Θέματα** — Light / Dark mode
- **Αποθήκευση** — Αυτόματη αποθήκευση κατάστασης στο `localStorage`

## Εκκίνηση

Δεν απαιτείται εγκατάσταση ή server. Απλά ανοίξτε το `index.html` στον browser:

```bash
# Κλωνοποιήστε το repository
git clone https://github.com/giantariz/guessgame.git
cd guessgame

# Ανοίξτε στον browser
open index.html        # macOS
xdg-open index.html   # Linux
start index.html      # Windows
```

Ή απλά κάντε διπλό κλικ στο `index.html`.

## Πώς παίζεται

1. Μεταβείτε στην καρτέλα **Παίκτες** και προσθέστε τα ονόματα των παικτών.
2. Επιλέξτε κατηγορίες και ρυθμίστε το χρονόμετρο στις **Ρυθμίσεις**.
3. Πατήστε **Επόμενη Ερώτηση** — κάθε παίκτης λέει την εκτίμησή του.
4. Αποκαλύψτε την απάντηση και δώστε πόντους στον παίκτη που πλησίασε περισσότερο.
5. Στο τέλος, ο παίκτης με τους περισσότερους πόντους κερδίζει.
