Αναβαθμισμένη έκδοση για παρέα

Τώρα με σκορ, χρονόμετρο, τυχαίες ερωτήσεις και δικά σου JSON sets

Ο host δείχνει μία ερώτηση τη φορά, βάζει timer ανά γύρο, αποκαλύπτει τη σωστή απάντηση όταν θέλει και δίνει πόντο στον παίκτη που ήταν πιο κοντά. Μπορείς να παίξεις είτε με το έτοιμο set των 50 ερωτήσεων είτε να φορτώσεις δικό σου.

Ρεαλιστική χρήση

Αυτό είναι host app για ζωντανό παιχνίδι παρέας. Δεν υπολογίζει αυτόματα ποιος ήταν πιο κοντά, γιατί οι παίκτες γράφουν απαντήσεις offline και ο host απονέμει πόντο.

Καλός τρόπος παιχνιδιού

Ξεκινάς γύρο, τρέχει timer 30–45'', κλείνεις απαντήσεις, εμφανίζεις λύση, και μετά δίνεις πόντο από το scoreboard στον νικητή του γύρου.
